# Портфолио Ивана Лазарева

Готовая версия сайта для GitHub: русская — `index.html`, английская — `en.html`.
Обе страницы используют один дизайн, общие изображения, видео и анимации.
Переключение языка сохраняет положение на странице.
Для мобильных кейсов подключены отдельные вертикальные обложки из Figma,
выгруженные в 2× (1920 × 3120 px); десктоп использует горизонтальные изображения.

## Как загрузить

1. Создайте или откройте репозиторий на GitHub.
2. Выберите **Add file → Upload files**.
3. Загрузите **содержимое этой папки**: `index.html` и `en.html` должны оказаться
   в самом корне репозитория рядом с `site.js` и папкой `assets`.
4. Сохраните загрузку через **Commit changes**.

В пакете 97 файлов, примерно 17.4 МБ.
Каждый файл меньше 25 МБ, поэтому пакет укладывается в ограничения одной
загрузки через браузер. Скрытые `.nojekyll` и `.gitignore` также включены;
в Finder их можно показать сочетанием **⌘ Shift .**.

## Как включить сайт на GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В **Source** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
4. После публикации GitHub покажет адрес сайта.

Русская версия открывается по основному адресу, английская — по тому же адресу
с окончанием `/en.html`. Пути относительные: сайт работает и в подпапке
вида `https://ваш-логин.github.io/название-репозитория/`.
Для просмотра сайта нужен именно адрес GitHub Pages; обычная страница
репозитория показывает файлы.

Сборка, Node.js и установка зависимостей для публикации не нужны.
Пустой `.nojekyll` оставляет готовые файлы без обработки шаблонизатором Jekyll.

## Просмотр на компьютере

На Mac дважды нажмите **«Запустить сайт.command»**. Нужен Python 3.9 или новее,
дополнительные библиотеки не требуются. `server.py` нужен только для локального
просмотра; GitHub Pages самостоятельно обслуживает статические файлы.

## Что находится внутри

- `index.html`, `en.html` — готовые страницы.
- `site.js` — модули сайта, объединённые в прежнем порядке; перед каждым модулем
  есть комментарий с его исходным именем.
- `assets/optimized` — используемые веб-изображения, шрифты, главное видео и стили.
- `assets/videos` — четыре ролика проектов.
- Остальные файлы `assets` — SVG, логотипы и иконки сайта.

Это самостоятельная копия для публикации. Исходные файлы для обработки медиа,
макеты, резервные копии и отчёты остаются в рабочей папке «Личный сайт».
Мобильные обложки этого выпуска обновлены отдельно в этой GitHub-копии.
При дальнейшем редактировании сохраняйте файлы `case-*@mobile.webp`
вместе с соответствующими превью и версиями в `site.js`, `index.html` и `en.html`.

Инструкции GitHub: [загрузка файлов](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository),
[включение Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
